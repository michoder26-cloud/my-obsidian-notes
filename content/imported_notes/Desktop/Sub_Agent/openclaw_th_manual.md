# 🤖 คู่มือการใช้งาน OpenClaw Multi-Agent Trading Desk (ภาษาไทย)

ยินดีต้อนรับสู่ระบบ **OpenClaw Trading Desk**! ระบบนี้ได้รับการติดตั้งและพร้อมใช้งานบนเครื่องของคุณอย่างสมบูรณ์แล้ว โดยทำหน้าที่เป็นโครงข่ายและระบบควบคุมกลางสำหรับกลุ่ม AI Agents นักเทรดทองคำ (XAU/USD) ของคุณ

---

## 🏗️ โครงสร้างการทำงานของระบบ (Architecture)

ระบบ OpenClaw ของคุณเชื่อมโยง **AI Agents** แต่ละตัวเข้ากับช่องทาง **Discord** เพื่อให้คุณสามารถพูดคุย สั่งการ และรับรายงานวิเคราะห์จากทีมเทรดได้ตลอด 24 ชั่วโมง:

```mermaid
graph TD
    User([คุณ / Owner 👤]) -->|คุยตรง/สั่งงาน| Discord[Discord Bot 💬]
    
    subgraph OpenClaw Gateway (รันเป็นเบื้องหลังในเครื่อง)
        Gateway[OpenClaw Gateway ⚙️] <--> Discord
        Gateway <--> Dashboard[Web Dashboard 📊]
    end

    subgraph ทีม AI Agents (มีโฟลเดอร์ของตัวเอง)
        CEO[👔 CEO Agent - ท่านประธาน] <--> Gateway
        Bull[🐂 Bull Agent - พี่กระทิง] <--> Gateway
        Bear[🐻 Bear Agent - พี่หมี] <--> Gateway
        Quant[📊 Quant Analyst - พี่ควอนท์] <--> Gateway
        News[📰 News Analyst - พี่ข่าว] <--> Gateway
    end
    
    %% การผูกช่อง (Bindings) บน Discord
    Discord -->|ช่องประธานตัดสินใจ| CEO
    Discord -->|ช่องอัปเดตข่าวสาร| News
```

| สมาชิกทีม | ชื่อบทบาท | หน้าที่หลัก | นิสัย/สไตล์การคุย | โฟลเดอร์ตั้งค่าหลัก |
| :--- | :--- | :--- | :--- | :--- |
| **👔 CEO Agent** | ท่านประธาน / บอส | ตัดสินใจขั้นตอนสุดท้ายว่าจะ BUY/SELL/HOLD โดยชั่งน้ำหนักจาก Bull/Bear/News/Quant | สุขุม, มีวินัยสูง, เน้นความปลอดภัยของเงินทุน | `~/.openclaw/ceo_agent-workspace` |
| **🐂 Bull Agent** | พี่กระทิง | หาเหตุผลและข้อมูลฝั่งขาขึ้น (BUY) เท่านั้น (มองแนวรับ, จุดลดราคา, ข่าวบวกต่อทอง) | พลังงานสูง, มองโลกในแง่ดี, ตื่นตัว | `~/.openclaw/bull_agent-workspace` |
| **🐻 Bear Agent** | พี่หมี | หาเหตุผลและข้อมูลฝั่งขาลง (SELL) เท่านั้น (มองแนวต้าน, โซนแพง, ข่าวลบต่อทอง) | ระมัดระวัง, สมจริงสมจัง, ขี้ระแวง | `~/.openclaw/bear_agent-workspace` |
| **📊 Quant Analyst**| พี่ควอนท์ | วิเคราะห์กราฟและเทคนิคอลล้วน ๆ (RSI, MACD, Bollinger Bands, ATR, Price Action) | แม่นยำ, ยึดตัวเลขเป็นหลัก, ไม่มีอคติ | `~/.openclaw/quant_analyst-workspace` |

## 💬 วิธีการใช้งานและคุยกับ Agents บน Discord

ระบบ OpenClaw ได้เชื่อมต่อบอตเข้ากับบัญชี Discord ของคุณเรียบร้อยแล้ว โดยคุณสามารถคุยกับพวกเขาได้ตามช่องทางเหล่านี้:

### 1. คุยส่วนตัวกับบอต (Direct Message - DM)
*   **วิธีการ**: คลิกขวาที่ตัวบอตใน Discord แล้วเลือกส่งข้อความส่วนตัว (DM)
*   **ผลลัพธ์**: คุณจะคุยกับ **Main Agent** (บอตตัวหลัก) เพื่อสั่งงานทั่วไป ค้นหาข้อมูล หรือสั่งรันคำสั่งบนเครื่องคอมพิวเตอร์ของคุณ

### 2. พูดคุยในห้องแชทเฉพาะ (Channel Bindings)
ในไฟล์ตั้งค่าปัจจุบันของคุณ ได้มีการผูก (Bind) บอตแต่ละตัวเข้ากับห้องเฉพาะใน Discord เรียบร้อยแล้ว:
*   **📰 ช่องคุยกับพี่ข่าว (News Analyst)**: 
    *   **Discord Channel ID**: `1504080403252645898`
    *   **สิ่งที่คุณทำได้**: พิมพ์คุยในห้องนี้ พี่ข่าวจะคอยตอบเรื่องเศรษฐกิจและปัจจัยมหภาคที่ส่งผลต่อราคาทองคำ
*   **👔 ช่องคุยกับท่านประธาน (CEO Agent)**: 
    *   **Discord Channel ID**: `1504080533175664681`
    *   **สิ่งที่คุณทำได้**: พิมพ์คุยเพื่อถามความเห็นหรือกดดันให้ท่านประธานตัดสินใจว่า ณ เวลานี้ ควรถือ BUY, SELL หรือ HOLD

> *   หากอยากให้อัปเดตเรื่องเฉพาะเจาะจง ให้แฮชแท็กหรือแท็กชื่อตัวบอตเพื่อความมั่นใจ

## 🖥️ วิธีการจัดการและตรวจสอบระบบผ่านเครื่องคอมพิวเตอร์ของคุณ

OpenClaw ทำงานเป็น Service เบื้องหลังในระบบ Windows ของคุณ (ผ่าน Scheduled Task) ทำให้คุณไม่ต้องเปิดหน้าต่าง Command Prompt ค้างไว้ตลอดเวลา โดยคุณสามารถควบคุมและตรวจสอบได้ดังนี้:

### 1. ดูหน้าควบคุมของระบบ (Web Dashboard)
คุณสามารถเข้าไปดูสถานะ, การสนทนา, และ Logs ทั้งหมดของระบบแบบสวยงามผ่านเว็บเบราว์เซอร์ของคุณได้ที่:
🔗 **[http://127.0.0.1:18789](http://127.0.0.1:18789)**

> [!IMPORTANT]
> ระบบมีการตั้งระบบความปลอดภัย (Token Authentication)
> *   **Token ปัจจุบันของคุณคือ**: `8aa2913f73cd871d163e5cae5092b9d949accc32470d459f`
> *   หากเปิดหน้าเว็บแล้วระบบถามหารหัสผ่านหรือ Token ให้นำชุดรหัสด้านบนไปกรอกได้ทันทีครับ

### 2. คำสั่งควบคุมผ่าน Windows PowerShell / Command Prompt
คุณสามารถพิมพ์คำสั่งต่อไปนี้ในโปรแกรม PowerShell เพื่อควบคุมและตรวจสอบ OpenClaw:

*   **เช็คสถานะการทำงานทั้งหมด**:
    ```powershell
    openclaw status
    ```
    *(เพื่อเช็คว่าเครื่องมือเชื่อมต่อกับ Discord เรียบร้อยดีหรือไม่ และมี Session ไหนกำลังทำงานอยู่)*

*   **ดู Logs การทำงานแบบ Real-time (มีประโยชน์มากเวลาบอตไม่ตอบ):**
    ```powershell
    openclaw logs --follow
    ```

*   **เช็คสุขภาพของระบบและแก้ไขปัญหาอัตโนมัติ**:
    ```powershell
    openclaw doctor
    ```

*   **สั่งเปิดหน้าควบคุมบนเว็บโดยตรง**:
    ```powershell
    openclaw gui
    ```

## ❓ คำถามที่พบบ่อย (FAQs)

*   **ถาม: บอตไม่ตอบใน Discord ทำอย่างไรดี?**
    *   **ตอบ**: ให้ลองเปิด PowerShell แล้วพิมพ์ `openclaw status` เพื่อเช็คว่าบอตสถานะเป็น `OK` หรือไม่ หากระบบ Gateway หลุดหรือค้าง สามารถสั่งรีสตาร์ทระบบได้ด้วยคำสั่ง `openclaw gateway restart` ครับ
*   **ถาม: อยากตั้งค่าห้อง Discord เพิ่มต้องทำอย่างไร?**
    *   **ตอบ**: คุณสามารถแก้ไขไฟล์ `openclaw.json` ในส่วนของ `"bindings"` หรือใช้งานคำสั่ง `openclaw configure` เพื่อแก้ไขผ่านวิซาร์ดจำลองคำสั่งบนหน้าจอได้ทันทีครับ
*   **ถาม: อยากรันบ็อตให้เทรดบนกราฟจริงของระบบ XAU Trading System เลยได้ไหม?**
    *   **ตอบ**: ได้เลยครับ! ในตัวระบบ trading system ปัจจุบันมีตัวนำทางอย่าง `main.py` และ `orchestrator.py` ซึ่งสามารถรันเชื่อมโยงเพื่อนำข้อมูลมาให้เหล่าเซสชันใน OpenClaw วิเคราะห์ต่อได้ครับ
