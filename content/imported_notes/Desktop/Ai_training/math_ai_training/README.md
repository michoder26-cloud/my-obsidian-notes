# Math AI Training Lab

โปรเจกต์นี้คือห้องเรียนเริ่มต้นสำหรับให้ AI เรียนคณิตศาสตร์ที่เกี่ยวกับข้อมูลราคา โดยยังไม่เทรดจริง ยังไม่ต่อ API กระดานเทรด และยังไม่ใช้เงินจริง

เป้าหมายตอนนี้:

- เก็บความรู้คณิตศาสตร์ที่ใช้กับข้อมูลราคา
- แปลงสูตรคณิตศาสตร์เป็น Python function
- เตรียม feature ที่โมเดล AI สามารถเรียนรู้ได้
- สร้างพื้นฐานสำหรับการ train/backtest ในอนาคต

## แนวคิดสำคัญ

AI trading ไม่ได้เริ่มจากการให้ AI อ่านสูตรแล้วเทรดทันที แต่เริ่มจากการแปลงสูตรให้เป็นตัวเลข เช่น return, volatility, momentum, z-score แล้วให้โมเดลเรียนความสัมพันธ์ระหว่าง feature เหล่านี้กับผลลัพธ์ในอนาคต

ตัวอย่าง:

```text
ข้อมูลราคา -> สูตรคณิตศาสตร์ -> feature -> model -> prediction
```

ตอนนี้โปรเจกต์นี้ทำถึงขั้น:

```text
ข้อมูลราคา -> สูตรคณิตศาสตร์ -> feature
```

ยังไม่ทำ:

- ไม่ส่งคำสั่งซื้อขาย
- ไม่ต่อ exchange API
- ไม่ใช้เงินจริง
- ไม่สร้างบอทเทรดอัตโนมัติ

## ลำดับการเรียน

1. อ่าน `docs/training_plan.md`
2. อ่าน `docs/math_models.md`
3. เปิดดูสูตรใน `src/features.py`
4. ขั้นต่อไปค่อยเพิ่มไฟล์ดึงข้อมูลราคาและทดลองคำนวณ feature

## คำเตือน

โมเดลที่ดูดีในอดีตอาจล้มเหลวในอนาคตได้เสมอ ต้องระวัง overfitting, data leakage, fee, slippage และความเสี่ยงของตลาดจริง
