# ฉากที่ 1: ความสิ้นหวังก่อนสอบ
ภาพวาดลายเส้นอนิเมะ 2D คุณภาพสูง สไตล์ภาพยนตร์อนิเมะ โดเรมอน (Doraemon) ลายเส้นสะอาด ลงสีสดใส ในห้องนอนเสื่อทาทามิที่รกรุงรังไปด้วยหนังสือเรียน โนบิตะ (Nobita) จากการ์ตูนเรื่องโดเรมอน เด็กชายใส่แว่นตากลม เสื้อสีเหลือง กางเกงขาสั้นสีน้ำเงิน กำลังนั่งร้องไห้ฟูมฟายด้วยความเครียด โดยมี โดราเอมอน (Doraemon) จากการ์ตูนเรื่องโดเรมอน แมวหุ่นยนต์สีฟ้าตัวกลม ยืนมองดูอยู่ข้างๆ ด้วยความกังวลและพยายามช่วยเหลือ กล้องซูมเข้าช้าๆ ที่ใบหน้าของโนบิตะ

# ฉากที่ 4: การทำข้อสอบอย่างมั่นใจ
ภาพวาดลายเส้นอนิเมะ 2D คุณภาพสูง สไตล์ภาพยนตร์อนิเมะ โดเรมอน (Doraemon) ลายเส้นสะอาด ลงสีสดใส ในห้องเรียนของญี่ปุ่นที่มีแสงแดดส่องสว่าง โนบิตะ (Nobita) จากการ์ตูนเรื่องโดเรมอน เด็กชายใส่แว่นเสื้อเหลือง นั่งอยู่ที่โต๊ะเรียนและเขียนคำตอบลงในกระดาษข้อสอบอย่างรวดเร็วและมั่นใจปนรอยยิ้ม ชิซุกะ (Shizuka) จากการ์ตูนเรื่องโดเรมอน เด็กผู้หญิงมัดผมแกละสองข้างใส่เสื้อสีชมพู นั่งอยู่ที่โต๊ะข้างๆ หันมามองโนบิตะด้วยความตกตะลึงสุดขีด กล้องแพนจากโนบิตะไปยังชิซุกะ
