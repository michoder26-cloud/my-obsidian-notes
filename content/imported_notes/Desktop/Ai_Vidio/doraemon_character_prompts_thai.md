# 1. โดราเอมอน (Doraemon)
ภาพวาดลายเส้นอนิเมะ 2D คุณภาพสูง สไตล์ภาพยนตร์อนิเมะ โดเรมอน (Doraemon) ยืนตรง ยิ้มแย้มอย่างมีความสุข ตัวแมวหุ่นยนต์สีฟ้าตัวกลม หน้าขาว มีหนวดกลมๆ ปลอกคอสีแดงพร้อมกระดิ่งสีทอง กระเป๋าหน้าท้องกลมสีขาวครึ่งวงกลม ฉากหลังสีขาวล้วนสะอาดตา ภาพแนวตั้งเต็มตัว ชัดเจน

# 2. โนบิตะ (Nobita)
ภาพวาดลายเส้นอนิเมะ 2D คุณภาพสูง สไตล์ภาพยนตร์อนิเมะ โดเรมอน (Doraemon) โนบิตะ (Nobita) เด็กชายชาวญี่ปุ่นอายุ 10 ปี ยืนตรงและยิ้มแย้ม ใส่แว่นตากลมหนากรณีสีดำ ผมสั้นสีดำ เสื้อโปโลคอปกสีเหลืองสดใส กางเกงขาสั้นสีน้ำเงิน ถุงเท้าขาวและรองเท้าสีน้ำเงิน ฉากหลังสีขาวล้วนสะอาดตา ภาพแนวตั้งเต็มตัว ชัดเจน

# 3. ซึเนโอะ (Suneo)
ภาพวาดลายเส้นอนิเมะ 2D คุณภาพสูง สไตล์ภาพยนตร์อนิเมะ โดเรมอน (Doraemon) ซึเนโอะ (Suneo) เด็กชายตัวเตี้ย ยืนยิ้มอย่างมั่นใจ ผมสีน้ำตาลแหลมชี้ไปข้างหน้าสามแฉกอันเป็นเอกลักษณ์ เสื้อโปโลสีเขียวอมฟ้า (Teal) กางเกงขาสั้นสีน้ำตาล รองเท้าสีฟ้า ฉากหลังสีขาวล้วนสะอาดตา ภาพแนวตั้งเต็มตัว ชัดเจน

# 4. ไจแอนท์ (Giant)
ภาพวาดลายเส้นอนิเมะ 2D คุณภาพสูง สไตล์ภาพยนตร์อนิเมะ โดเรมอน (Doraemon) ไจแอนท์ (Giant) เด็กชายตัวใหญ่สูงและท้วม ผมสั้นหยักศกสีดำ ยืนเอามือกุมสะโพกและยิ้มกว้าง ใส่เสื้อยืดสีส้มสดใสที่มีแถบลายซิกแซกสีน้ำตาลแนวนอนพาดตรงกลางหน้าอก กางเกงขาสั้นสีน้ำเงิน รองเท้าผ้าใบสีเทา ฉากหลังสีขาวล้วนสะอาดตา ภาพแนวตั้งเต็มตัว ชัดเจน

# 5. ชิซุกะ (Shizuka)
ภาพวาดลายเส้นอนิเมะ 2D คุณภาพสูง สไตล์ภาพยนตร์อนิเมะ โดเรมอน (Doraemon) ชิซุกะ (Shizuka) เด็กผู้หญิงน่ารักอายุ 10 ปี ยืนยิ้มหวานสุภาพ ผมสีน้ำตาลเข้มมัดแกละสองข้าง เสื้อเชิ้ตสีชมพู กระโปรงสั้นสีน้ำเงินเข้ม ถุงเท้าสีขาว รองเท้าสีชมพู ฉากหลังสีขาวล้วนสะอาดตา ภาพแนวตั้งเต็มตัว ชัดเจน
