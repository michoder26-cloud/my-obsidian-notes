# วิธีอธิบายโค้ดเป็นภาษาไทย

เมื่อ skill นี้ถูกเรียก ให้ทำตามขั้นตอนต่อไปนี้:

## ขั้นตอนที่ 1: อ่านโค้ด
- ถ้าผู้ใช้ระบุไฟล์ ให้ใช้ Read tool อ่านไฟล์นั้น
- ถ้าไม่ระบุ ให้ถามว่าอยากให้อธิบายไฟล์ไหน

## ขั้นตอนที่ 2: อธิบายตามรูปแบบนี้

### สรุปสั้นๆ
อธิบายภาพรวมว่าโค้ดนี้ทำอะไร 1-2 ประโยค

### ส่วนประกอบหลัก
แยกอธิบายเป็นส่วนๆ:
- **ส่วนที่ 1**: ทำหน้าที่อะไร
- **ส่วนที่ 2**: ทำหน้าที่อะไร

### จุดที่น่าสนใจ
- เทคนิคพิเศษหรือ pattern ที่ใช้
- ข้อควรระวัง หรือ bug ที่อาจเกิด

### ตัวอย่างการใช้งาน
ถ้าเป็นฟังก์ชัน ให้ยกตัวอย่าง input/output

## กฎสำคัญ
- ใช้ภาษาไทยเป็นหลัก แต่คงคำศัพท์เทคนิคภาษาอังกฤษไว้ (เช่น function, array, async)
- หลีกเลี่ยงศัพท์ยากๆ ถ้าจำเป็นต้องใช้ ให้อธิบายความหมายด้วย
- ใช้ตัวอย่างและการเปรียบเทียบกับชีวิตประจำวันถ้าช่วยให้เข้าใจง่ายขึ้น
