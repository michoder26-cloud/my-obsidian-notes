# 🎯 Mastering the Art of Scalping and Sniper Trading Strategies

จากการศึกษา NotebookLM เรียนรู้เทคนิค Scalping และ Sniper Trading ที่เหมาะสำหรับผู้เล่นระยะสั้น

---

## 📌 บทนำ

Scalping เป็นเทคนิคการเทรดแบบระยะสั้นมากที่ เป้าหมายคือการทำกำไรเล็กน้อยซ้ำๆ จนเก็บกำไรได้มากขึ้น เหมาะสำหรับผู้เล่นที่มีวินัยสูง กล้าตัดสินใจไว และมีพอร์ตให้ใช้ได้เพียงพอ

---

## 🎪 เทคนิคที่ 1: Scalping ในกรอบ Sideways (วิ่งเป็นคลื่น 100-200 จุด)

### 🎯 ลักษณะเด่น
- **Timeframe**: M5 หรือ M15
- **ผลกำไร**: 100-200 จุดต่อครั้ง
- **โครงสร้าง**: ราคาวิ่งเป็นคลื่นขึ้นลงในช่วง Sideways (ไม่มีเทรนด์ชัดเจน)
- **ความเสี่ยง**: สูง - ต้องระวังการถูกลากจากการสวิงเป็นเทรนด์รุนแรง

### ✅ Entry Signals (สัญญาณเข้า)

1. **ค้นหาจังหวะที่กราฟเกิด Sideways**
   - ราคาวิ่งขึ้นลงอย่างสม่ำเสมอ ไม่มีการเคลื่อนไหวรุนแรง

2. **หาแนวต้าน (Resistance) และแนวรับ (Support) ระยะสั้น**
   - สังเกตจาก Pivot Point หรือเส้น EMA

3. **เข้าออเดอร์ที่จุดแตะแนวต้าน/รับ**
   - ราคาชนแนวต้านด้านบน → **SELL (Sell)**
   - ราคาชนแนวรับด้านล่าง → **BUY (Buy)**

4. **สามารถเล่นหลายรอบได้**
   - ขึ้นไปขายที่ต้าน → ลงมาซื้อที่รับ → ขึ้นไปขายอีก (วนซ้ำ)

### 🛑 Exit Signals (สัญญาณออก)

1. **Take Profit (TP) ไว้ที่ 100-200 จุด เท่านั้น**
   - จำเป็นต้องวิ่งให้ถึงเป้า กำไร

2. **ปิดทำกำไรเมื่อราคาชนเส้น EMA**
   - มีความเสี่ยงที่จะเกิด Rebound ขึ้นอย่างรวดเร็ว
   - เลิกตีความคิดเห็นด้วยตัวเอง ให้วินัยควบคุม

3. **ตัดสินใจปิดเหมือนกับเล่นหลายรอบได้**

### 🎲 Risk Management (การจัดการความเสี่ยง)

**หลักการ 1:1 (Ratio SL:TP)**
```
ถ้า TP = 100 จุด → SL ต้อง = 100 จุด เท่านั้น
ถ้า TP = 200 จุด → SL ต้อง = 200 จุด เท่านั้น
```

**วินัยในการตัดขาดทุน**
- ✅ **ต้องมีความกล้า** ตัดขาดทุนเมื่อชน SL
- ❌ **ห้ามปล่อยให้ลากตัวเด็ดขาด**
- เพราะว่าการเล่นแบบนี้ไม่เหมาะสมกับการเทรดสั้น อาจทำให้พอร์ตแตก

### 💡 Best Practices (วิธีปฏิบัติที่ดี)

✅ **เล่นเมื่อ:**
- กราฟเกิด Sideways ชัดเจน
- ไม่มีข้อมูลทางการเมือง/เศรษฐกิจสำคัญ ๆ

❌ **ห้ามเล่นเมื่อ:**
- กราฟกำลังวิ่งเทรนด์รุนแรง (ขึ้นชัด หรือ ลงชัด)
- ตลาดยังไม่เปิดเต็มตัว ค่า Spread อาจจะถ่าง (Spread กว้าง = ปิดกำไรได้ยากขึ้น)

## 🎯 เทคนิคที่ 2: Scalping Break & Retest (นิวยอร์คเปิด)

### 🎪 ลักษณะเด่น
- **Win Rate**: ~90% (ที่ผ่าน Backtest)
- **Timeframe**: M5 (อ้างอิง) + M1 (เข้าเทรด)
- **เวลาที่ดี**: 20:30 น. (เวลาไทย) = 9:30 น. (นิวยอร์ก)
- **R:R Ratio**: 1:2 ขึ้นไป

### ✅ Entry Signals (ขั้นตอนการเข้า)

**ขั้นตอน 1: อ้างอิง Timeframe M5**
```
⏰ เวลา 20:30 น. (เวลาไทย)
📊 เลือก Timeframe M5
📍 แท่งเทียนแรก = 5 Minute Opening Range
```

**ขั้นตอน 2: มาร์คจุดสูงสุดและต่ำสุด**
```
📌 Mark HIGH ของแท่ง M5 แรก
📌 Mark LOW ของแท่ง M5 แรก
↓
ใช้เป็นกรอบอ้างอิงในการเล่น
```

**ขั้นตอน 3: ลด Timeframe เป็น M1**
```
🔍 ลดลงมาดูที่ M1 (1 นาที)
🎯 รอให้ราคาเบรค (Break) ด้านใดด้านหนึ่ง
```

**ขั้นตอน 4: เบรค ด้วยเนื้อเทียนเท่านั้น**
```
❗ สำคัญ: ต้องเบรคด้วย "เนื้อเทียน" ชัดเจน ไม่ใช่แค่ไส้เทียน
⚠️ ระวัง "ไส้ยาว" (Wick) อาจหลอก
```

**ขั้นตอน 5: รอให้กลับมา Retest**
```
↩️ ราคาจะวิ่งกลับมา Retest บริเวณเส้นแนว
   ที่มันเพิ่งทะลุไป (Support/Resistance)
```

**ขั้นตอน 6: รอแท่ง Confirmation**
```
🕯️ ต้องรอให้เกิดแท่งเทียน Confirmation ขนาดใหญ่
✅ ที่มีเนื้อเทียนชัดเจน ใน "ทิศทางที่ต้องไป"
❌ ห้ามเข้าเมื่อ:
   - Retest แล้ว "ไม่มีแท่ง Confirmation"
   - Retest แล้ว Wick ยาวเกินไป
   - อาจเป็นการหลอก (Fake Out)
```

### 🛑 Exit Signals (ออกจากตำแหน่ง)

- ทำกำไรตามระบบ
- อัตรา R:R (Risk to Reward) ควรเป็น **1:2 ขึ้นไป**
- ปิดกำไรเมื่อราคาไปตามแผน

### 🎲 Risk Management (การจัดการความเสี่ยง)

**วางจุด Stop Loss (SL)**
```
📍 SL = ใต้แท่ง Confirmation ที่ใช้ยืนยันการเข้า
   ไม่ได้ตั้งไว้ที่ลึกเท่านั้น แต่อยู่ในทำเนียบสม่ำเสมอ
```

### 💡 Best Practices (วิธีปฏิบัติที่ดี)

✅ **ต้องปฏิบัติ:**
- ✅ วิเคราะห์ Trend ภาพใหญ่ (Higher Timeframe)
- ✅ รอแท่ง Confirmation ที่มีเนื้อเทียนชัดเจน
- ✅ หลีกเลี่ยงการเล่นเมื่อ Fake Out เกิดขึ้น

❌ **ห้ามทำ:**
- ❌ เข้าออเดอร์แบบ "เด็ดขาด" โดยไม่รอ Confirmation
- ❌ เข้าเมื่อการทะลุกรอบไม่ได้ทะลุด้วยเนื้อเทียนที่ชัดเจน
- ❌ ลืมวิเคราะห์ Trend ภาพใหญ่
